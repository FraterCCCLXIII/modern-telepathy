Gallery of experiments

Pieces of an interface kit, side by side.

Shells, chat parts, form controls, cards, full app views and site sections from one workspace. Every preview is the real React component, running on sample data.

Where this comes from. These components are from the owner's private UI Experiments workspace (longformer-ui v with its demo and site). They are not a released package. Each tile says which file it comes from and how far it goes: available is named as a settled primitive or has a strict schema, prototype exists but is demo or planned-extraction tier, unverified is not classified anywhere in the workspace, and planned is a placeholder for something the plans name but no source exists for. The blocks and primitives already shown on the Arco components and docs page are not repeated here.

What is shown

    How it is built

    The sources are copied to a temp folder and bundled with esbuild and React 18.3.1 into three lazy-loaded bundles (assets/uix-core.js, uix-apps.js, uix-site.js, sharing chunks), each loaded only when a tile of that kind scrolls near the screen. The kit's dark default is removed from :root so nothing leaks to this page. Props tables are read from the TypeScript sources. Steps are in README.md beside this page.
