Introducing Hands

The new agent avatars.

Twelve hands on one plane, each with its own colour and its own cycle of moves. An idea for how a team of agents could look when they all work at once.

Every agent in a conversation gets a little hand of its own: a colour, a mood that follows what it is doing, and a motion for waiting, thinking and finishing. They are made with Kosmos, the same characters and engine work behind Kamiji.

What Hands is

Hands brings coding agents together in one place. You start a conversation, point it at a project, and an agent reads the code, runs commands, edits files and reports back. You can also set agents to run on a schedule or when something happens, such as a GitHub event.

It is a control center rather than a single model. It runs its own open source agent out of the box, can drive other agents that speak the Agent Client Protocol, and works with the language model of your choice.

Products

  • Agent Canvas GUI

    The browser control center for agent conversations and automations. It runs locally by default and can switch between several backends. The README marks it as beta.

  • Agent Server server

    A REST and WebSocket server that runs agents on a host. Run it on a laptop, a dedicated machine, a virtual machine or in the cloud, and connect the canvas to as many as you like.

  • Software Agent SDK SDK

    A Python library for building agents that use tools, workspaces and conversations. Use it to put agents inside your own tools.

  • CLI terminal

    The same agent in your terminal, installed with uv or an install script.

  • Automation Server schedules

    Starts agents on a schedule or from webhook events, and keeps a run history. It is a separate repository that pairs with the Agent Server.

  • Cloud and Enterprise hosted

    A managed cloud with hosted execution, integrations and usage controls, and an enterprise option for licensed self-hosting or managed deployment.

Sources: Agent Canvas README, docs.openhands.dev, openhands.dev, github.com/OpenHands.

How it works

  • Agents

    The built-in OpenHands agent, plus Claude Code, Codex, Gemini CLI, Pi, OpenCode or any agent that speaks the Agent Client Protocol (ACP).

  • Runtimes

    Run on the host directly, in one Docker sandbox, or in a separate container for every conversation. The SDK also documents Apptainer and API-based sandboxes.

  • Backends

    Connect the canvas to local, remote and cloud agent servers and switch between them without leaving the page. Share one server with a team and keep a personal one on your laptop.

  • Subagents

    An agent can hand work to other agents. The SDK has a task tool set and file-based agent definitions for this.

  • Automations

    Reports to Slack, GitHub issues broken into tasks, and similar jobs, run on a schedule or from a webhook.

  • MCP and skills

    Connect tools through the Model Context Protocol and give agents reusable skills. Public skills live in the extensions repository.

  • Any model

    Bring your own language model and keep several LLM profiles.

Get started

Check the sources. Package and image names still say openhands. Commands are copied from the files named under each block.

Agent Canvas from the repo

Needs Node.js 24 or later and uv. This runs the agent server on your machine with access to your files, so read the README warning first.

npm install -g @openhands/agent-canvas
agent-canvas

Source: README.md, Option 1. Then open http://localhost:8000.

Docker sandbox

export PROJECTS_PATH="$HOME/projects"
mkdir -p "$PROJECTS_PATH" "$HOME/.openhands"

docker run -it --rm \
  -p 127.0.0.1:8000:8000 \
  -e AGENT_CANVAS_ALLOW_LAN_SESSION_KEY=true \
  -v "$HOME/.openhands:/home/openhands/.openhands" \
  -v "${PROJECTS_PATH}:/projects" \
  ghcr.io/openhands/agent-canvas:1.29.0

Source: README.md, Option 2. Docker serves the UI at http://localhost:8000/canvas.

One container per conversation

npm install -g @openhands/agent-canvas
OH_CONVERSATION_RUNTIME=docker agent-canvas

Source: README.md, Option 3.

From source

git clone https://github.com/OpenHands/OpenHands.git
cd OpenHands
npm install
npm run dev

Source: README.md, Option 4.

CLI and SDK from the docs

CLI

uv tool install openhands --python 3.12
openhands

Source: docs.openhands.dev, CLI installation page, fetched 24 Oct 2026. Needs Python 3.12 or later.

Python SDK

pip install -U openhands-sdk openhands-tools

Source: docs.openhands.dev/sdk/getting-started. Install both packages together so versions match.
