Generative AI operating system

What Kosmos is

Kosmos is a generative AI operating system for integrated work and life. One shell for chat, code, files, and generated apps, with agents that share focus context across every workspace. It is not a chat sidebar bolted onto an IDE: it owns the shell, the workspaces, the agent UX, the app platform and the APIs that clients and the SDK talk to.

One shell for work and life

Chat, code, files, and generated apps share one focus model. Agents keep context across every workspace.

Kosmos Cloud Beta

Provision a private hosted instance at app.kosmos.computer. Manage billing, storage and credits from Settings. Or run it locally, or self-host.

Desktop, mobile, browser

Electron desktop, Android APK, Chromebook, SteamOS and browser or PWA. Thin clients connect to your instance.

Arco generative UI

Typed tokens, components and blocks that agents assemble inside Kosmos. Kosmos is the OS; Arco is the UI library inside it.

Key features

Built as an operating system for agents

  • Stable shell

    Nav rail, sidebar, main and context panel. Switch workspaces without reshuffling chrome.

  • Agent surface

    Chat, Orchestrator, Psyche and inline generated UI. The brain stays in the context panel.

  • Techno Studio

    Terminals, diffs, repo work and live preview in one agent canvas, embedded rather than a separate product tab.

  • Generated apps

    Describe an app in chat; Arco renders it inside Desktop windows and the Apps grid.

  • Longformer

    A transcription studio for long-form audio: upload, chapterize, clip and edit.

  • Agent cursor

    A visible cursor that clicks, types and demonstrates apps on the desktop.

  • Full-duplex voice

    Local speech to text and text to speech with barge-in. Swap brain, STT and TTS slots from one models hub.

  • Avatar sprite

    Swappable face rigs and programmable pixel marks that animate with voice and status.

    Kosmos SDK MIT

    Official TypeScript client

    Connect your apps, scripts and automations to a Kosmos environment: a local desktop, a self-hosted server or a hosted tenant. Mint an external client token in Settings, External Access. The SDK talks to Kosmos server APIs; it is not the App Bridge SDK for iframe apps inside the shell.
