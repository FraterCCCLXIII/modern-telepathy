What you get

  • Kamiji hand available

    One rigged GLB with a finger skeleton, face morph targets and four clips: Idle, Wave, Think, Celebrate. The React component adds more motions such as Spin, Bounce and Typing.

  • Tint per agent available

    Any CSS colour. A helper picks a stable colour from an agent name, so every agent keeps its own look.

  • Expressions and poses available

    Eight expressions (neutral, happy, excited, thinking, sad, angry, surprised, sleepy), hand poses, and a talking mouth.

  • Shape morphs available

    The hand blends into a sphere or a rounded cube and back.

  • Emotes and Git icons available

    Small animated emotes over the avatar, and GitHub status icons, as React components.

  • 14 Kamikin mochi available

    Skinned GLB characters with idle clips and six swappable face states (neutral, blink, happy, joy, surprised, sad). Listed in assets/mochi/index.json.

  • 16 Rubbernose characters available

    Skinned 1930s cartoon GLBs (eraser, alarm clock, soda can, sunflower, mug, pudding, light bulb, rocket, bell, cake, gift box, trash can, padlock, apple, cloud, trophy) with nine clips, six face states and a tintable body. Listed in assets/rubbernose/index.json.

  • Emoji prop library available

    24 clay-style 3D props (heart, star, check, fire, gear and more) in assets/props/, tintable by material colour. First batch; a React component for them is in progress.

  • Framework-free core and web component planned

    A <kamiji-avatar> element so non-React apps can use the hand.

      Install

      Private repository. You need access to the repo to follow the Today steps. There is no public download, npm package or CDN build yet.

      Today works now

      Use the React component by vendoring it into your app. This is how OpenHands uses it.

      1. Clone the repository (access required): 
        git clone https://github.com/FraterCCCLXIII/kamiji.git
      2. In your app (React 19 or newer), install the three dependencies the library uses, at the pinned versions: 
        npm install three@0.186.1 react-icons@5.6.0
      3. Copy src/ and assets/kamiji.glb into your app, keeping that layout, for example: 
        vendor/kamiji/src/
vendor/kamiji/assets/kamiji.glb
        The component finds the model with new URL("../assets/kamiji.glb", import.meta.url), so the relative path must stay, and your bundler must support that pattern (Vite does).
      4. Use it: 
        import { KamijiAvatar } from "./vendor/kamiji/src";
import "./vendor/kamiji/src/kamiji.css"; // emote animations

export function Agent() {
  return (
    <KamijiAvatar
      color="#ffd23f"
      expression="happy"
      pose="peace"
      size={96}
      alt="Planner agent"
    />
  );
}

      Props: color, expression, animation, pose, poseDurationMs, speaking, lockFace, shape, shapeDurationMs, size, className, alt. The index also exports KamijiWithEmote, KamijiGitIcon and KamijiHandsUp.

      The 3D scene loads lazily and one WebGL renderer serves every avatar. Without WebGL, or with reduced motion on, it shows a flat SVG hand.

      Mochi: copy assets/mochi/ and load the GLBs with three.js yourself. There is no mochi React component yet.
