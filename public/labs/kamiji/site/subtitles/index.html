    What is real and what is simulated

    • Real: line splitting, timing, the styles, reading-speed checks, SRT/WebVTT/JSON import and export, the accessibility transcript, saved settings, canvas drawing.
    • Simulated: there is no recorded audio. Word times are estimated from text length (syllable-like weights), except for lines you load from a WebVTT file that carries its own word stamps. The two faces are plain SVG stand-ins whose mouths follow the talking event; they are not the 3D avatar.
    • Play with voice uses your browser's built-in system voice only (speechSynthesis, no network). If the voice sends word boundary events the highlight follows them; if it does not, the module falls back to the estimated timing.
    • Not done: translation (the Japanese and Arabic lines are hand-written samples), speech recognition, and wiring into Previs, the chat widget or the avatar. See the README for the integration plan.
