browser/engine: host Chrome to display list (spike)

Edited 2026-10-27browser/engine/README.md

Host side only. Python 3 stdlib, plus PIL (installed) for images and compare.

Run#

Chrome 156.0.8078.48 from /Applications/Google Chrome.app, --headless=new, throwaway profile in the scratchpad, 1440x900, DPR 1. Only our own process tree is killed.

Display list JSON#

  • box: r, f fill #rrggbb[aa], b {w:[t,r,b,l], c}, rad
  • text: r line box, s ASCII, u original Unicode (only if non-ASCII), fs, fw, col, it, ul, ff
  • img: r, src absolute (null for svg), nat [w,h], bg, local file after --images
  • link: r, href. ctl: r, tag, type, val, ph. media: r, tag
  • o opacity (product down the DOM), c clip index

Chrome startup 0.32 s. Tree RSS about 1 GB idle, 2.1 GB peak. Images: wikipedia 5/78 (47 KB), BBC 11/30 (594 KB), maps 26/26 (1.06 MB). Fidelity = share of 16x16 tiles within 12.

Bytes#

Text dominates: Wikipedia text is 225 KB of 294 KB (u duplicate, inline ff, per-line r). Fixes: u only when needed; style table; merge lines of a paragraph; integer coords; cull offscreen.

Worked#

  • Stdlib CDP over WebSocket; DOMSnapshot gives lines, boxes, paint order at once.
  • Click on the example.com link navigated to iana.org. Typing filled the Wikipedia search box (snapshot shows the value); Enter navigated.
  • Wheel: scrollY 800, rects unchanged (document space). Resize to 800 px reflowed text.

Did not work or is missing#

  • Consent and bot walls: BBC Terms of Use dialog is not painted (score 0.097). Reddit serves "Prove your humanity". Google returned an almost empty page (title is the URL).
  • Canvas and WebGL (maps): only media boxes, so the map is unpainted. Fallback: screenshot tiles.
  • SVG not rasterised (count only). CSS gradients counted, not emitted (85 GitHub, 34 react.dev).
  • Wikipedia 0.69 and MDN 0.535 fidelity not investigated yet (painter is rough).
  • Light scheme forced; host is in dark appearance.
  • --disable-extensions used instead of the literal --disable-extensions-except nothing.

CDP methods#

Page. (navigate, lifecycle, getLayoutMetrics, captureScreenshot, getFrameTree, getResourceContent), DOMSnapshot.captureSnapshot, DOM.resolveNode, Runtime., Emulation.*, Input.dispatchMouseEvent/KeyEvent.

Next steps#

  1. Text run merging and a style table, target under 100 KB on Wikipedia.
  2. Viewport culling and streaming of the rest of the page.
  3. Screenshot-tile fallback for canvas, video, WebGL and SVG.
  4. Consent-wall detection before capture.
  5. Per-item diff to explain the Wikipedia and MDN fidelity gap.
