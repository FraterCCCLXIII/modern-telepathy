Clock suite and Launchpad: status (2026-10-27)

Edited 2026-10-27docs/apps/clock-launchpad-status.md

Files: desk3/03f-clock.HC (Clock app, notification toast), desk3/03g-launchpad.HC (Launchpad overlay, entry points KsOverlays, KsOverlayClick, KsExtraTick). Everything below was tested on x86 TempleOS (QEMU, 2x) on a private copy of commit 36f01472 plus my shared-file hunks, because the current tree stops earlier in 01-winstyle.HC (see Known problems).

Works and verified (shots/clock-.png, shots/launchpad-.png)#

  • World Clock: analogue face (integer sine table, anti-aliased hands, big-disk coverage tile), digital readout, 11 cities with fixed offsets, guest zone +/- buttons. The guest clock is the TempleOS Now(): it read 23:26 UTC while the host said 23:26 UTC. QEMU starts the RTC at host UTC; TempleOS has no zone, so the guest shows UTC and nothing syncs it with the host.
  • Stopwatch: start, stop, lap, reset; milliseconds from jiffies; lap table with best (green) and worst (red).
  • Timer: runs, counts down in step with the host clock, ring and Pause/Start. Alert (flashing ring plus toast) is in the code; the screenshot of the alert state was NOT taken. No sound (the guest has none; the PC speaker was not tried).
  • Alarms: add, set time, toggle; a one-off alarm fired on the second, a toast appeared and the alarm switched itself off.
  • Launchpad: grid of all apps from ks_an, hover scale, number badges, type-to-filter ("clo" leaves Clock), Backspace, Enter opens.
  • Benchmark (b), ms avg: full redraw 15.0 base, 16.2 with these files; drag large 5.4 / 5.8; drag small 3.4 / 4.0; dock warm 2.9 / 3.1. Idle QEMU CPU with the Monitor open: 52.7 percent base, 54.2 with the background tick (one run each, noisy).

Untested#

  • Arrow keys, Escape, number jump keys, click to open from the grid (only the key path L, text, Enter was driven).
  • Kosmos menu entry (item 4, shown first) and the L key against the current tree.
  • Timer alert, Timer presets after the preset id fix (ids 20 to 25 collided with city ids; cities are now 90 to 100).
  • Aiwnios: build.py writes the current tree and kslint.py is clean on both files, but the Aiwnios run and screenshots were not done.
  • Pause/Reset of the Timer, repeat day buttons, delete alarm.

Known problems#

  • Current tree does not compile on x86: 01-winstyle.HC (Windows app) calls WsScaleOf(a,ks_open[a],...) before ks_open exists (02-ui.HC). That error comes before 03g in load order; it is not in my files. HEAD also lacks the WS_* hooks (left uncommitted).
  • OpenApp is defined after my files and a forward call did not bind, so the Launchpad sets lp_req and Main (06-run.HC) opens it.
  • The toast shadow leaves a faint band at the top right. Selection follows the mouse pointer over tiles.
  • Launchpad has no Keep in Dock: the dock list (ks_dord) is fixed.

Shared-file hunks (uncommitted, in the working tree; ids by name, not number)#

  • 01-core.HC: NICON 32 (was 24) for ks_icd, ks_icm; L_CLOCK, L_TIMER, L_ALARM (icons appended to gen-icons.py NAMES); NA +1. 04-main.HC and 06-run.HC: NICON*260 in SelfTest and BenchAll.
  • 02-ui.HC: Clock appended to every app array and ks_dord; ks_kmi[5], new ks_kmo, KMenu (5 rows).
  • 04-main.HC: MenuAct (item 4 opens Launchpad), Click (KsOverlayClick first, menu band MBAR+190), AppClick (Clock), Keys (Launchpad key handler first, L key).
  • 06-run.HC: BodyOf (Clock), Draw (KsOverlays after KMenu), Main (KsExtraTick, lp_req open).
  • assets/KSICONS.BIN and scripts/gen-icons.py: three icons appended.
