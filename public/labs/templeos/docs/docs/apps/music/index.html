Music app: plan

Edited 2026-10-27docs/apps/music.md

Status: plan, not code. Branch task/templeos-shell. Written 2026-10-27. Read with docs/holyc-native-apps-plan.md, docs/core-apps-plan.md (Tier 2, Music) and docs/apps/00-kosmos-os-primitives.md (the os.music@1 contract). Registration follows docs/apps/applications-folder.md.

Tags: [V] checked in a repo or on this Mac, file named. [R] from a web search this session (snippets, URL given; pages were not opened). [M] from memory, to verify.

1. Purpose#

A native TempleOS player: browse by artist, album and folder, build a queue, show art, watch a spectrum. The Mac plays the audio, because TempleOS has no usable audio output (section 7). The guest draws everything. A separate, optional retro module plays HolyC sequences on the PC speaker (section 8).

2. Features and priorities#

Reference set: Apple Music, Spotify, Swinsian, Doppler, foobar2000, Navidrome and Subsonic clients, Koel.

Priority Feature Reference
P0 Local library from chosen folders: scan, tags, art, duplicate finder Swinsian: folder watching, tag editing, duplicates [R] (swinsian.com/support/about)
P0 Formats: MP3, AAC/M4A, ALAC, FLAC, WAV, AIFF, Ogg Vorbis Doppler plays FLAC, ALAC and WAV without conversion [R] (brushedtype.co/blog/doppler-for-mac); foobar2000 format list [R] (neowin.net/amp/foobar2000-v20/)
P0 Play, pause, next, previous, seek, shuffle, repeat, volume, mute all references
P0 Queue: add, remove, reorder, play next, clear foobar2000 playlist model [R]
P0 Now playing: art, title, artist, album, elapsed and remaining Apple Music, Spotify
P0 Keyboard first; / focuses search foobar2000
P1 Smart playlists (rules on tags, play count, last played), M3U import Swinsian smart playlists [R]
P1 Spectrum visualiser, bars with peak dots cava [R] (reference for band layout)
P1 Gapless playback, ReplayGain foobar2000 [R]
P1 Streaming from Subsonic servers (Navidrome) Navidrome implements Subsonic API v1.16.1 with exceptions [R] (navidrome.org/docs/developers/subsonic-api)
P1 Internet radio (stream URL list) Apple Music and Spotify radio
P2 Podcasts from RSS Kosmos musicRssService [V]
P2 Lyrics from tags or LRC files Koel Player lists lyrics [R] (apps.apple.com/app/id1576886982)
P2 Scrobbling Koel's listed integrations [R] (selfhostedworld.com, unverified)
Out Paid-catalogue playback (Apple Music, Spotify), DRM, store purchases, sync between devices Apple Music Sync Library needs a subscription [R] (support.apple.com/en-gb/guide/music/musa3dd5209/mac). Excluded: no accounts or sync in v1

Kosmos OS's os.music@1 contract [V: primitives 1.5] means the same library can later be read by the Kosmos app.

3. Architecture#

The guest owns UI and state. The host owns files, scanning, decoding and output.

Rules:

  1. Playback is on the host. A guest crash does not stop audio, and the guest never holds a stream URL with a token.
  2. Scanning is on the host. ffprobe -v error -show_format -show_streams -of json gives duration, codec, rate, channels and tags [V: /opt/homebrew/bin/ffprobe]. Koel uses getID3 for the same job [V: app/Services/Scanners/FileScanner.php]. mutagen is GPL-2.0-or-later [R] (pypi.org/project/mutagen) and is not installed [V], so it waits for a licence decision.
  3. Art is resized on the host to paint size. 64 by 64 RGB565 is 8,192 bytes; 96 by 96 is 18,432 bytes [estimate]. At the reported 47 KB/s serial rate that is 0.2 to 0.4 s; at the old 1.4 to 2.7 KB/s lockstep rate it is 3 to 13 s, so the art cache is required.
  4. Lists are paged. The guest asks for 32 rows at a time. The host never sends a whole library.

Library model (host SQLite, stdlib sqlite3): track, album, artist, playlist. Track ids are a hash of path and size, so a moved file keeps its play count after a rescan. Folders are chosen in a native host dialog.

4. Playback and control protocol#

4.1 Player helper#

Option Gets us Lacks Verdict
afplay [V: /usr/bin/afplay] play to end, volume pause, seek, state too thin
ffplay [V: /opt/homebrew/bin/ffplay] most formats window only, no IPC not headless
mpv [V: not installed] JSON IPC over a Unix socket: loadfile, pause, volume, time-pos, events [R] (mintlify.com/mpv-player/mpv/scripting/ipc-protocol) install; no spectrum over IPC; GPL build options [R] good P1 option
Swift helper on AVAudioEngine pause, seek, volume, installTap for FFT (Accelerate) Xcode CLT not checked; AVFoundation lacks Ogg Vorbis and Opus [M] recommended P0

Recommendation: a small Swift helper for P0. Formats AVFoundation cannot play are transcoded to a temporary WAV by ffmpeg on the host. mpv can replace the helper in P1 behind the same protocol. The helper speaks JSON lines on a local Unix socket, so it can be tested with nc -U.

4.2 Messages (new family 0x20 to 0x2F)#

The browser uses 0x01 to 0x14 and 0x7E/0x7F [V: browser-architecture b2]. This family is a proposal to reconcile with that table.

Code Name Payload
0x20 LIB_QUERY (G to H) view (songs, artists, albums, folders, playlists, radio, podcasts), filter, sort, offset, count
0x21 LIB_PAGE (H to G) total, rows: id, title, subtitle, duration, art hash
0x22 PLAY queue position or track id, start ms
0x23 TRANSPORT play, pause, toggle, next, prev, stop, seek ms, shuffle, repeat
0x24 VOLUME level 0 to 100, mute (host output only, not the Mac system volume)
0x25 QUEUE_EDIT add, remove, move, clear, play-next
0x26 STATE (H to G, at most 10 a second on change) status, track id, position ms, duration, queue length, volume
0x27 SPECTRUM (H to G) 16 bands of 1 byte at 10 frames a second
0x28 ART (H to G) hash, size, RGB565 (RLE optional), only if the guest lacks it
0x29 HAVE art hashes the guest holds
0x2A SCAN add root, remove root, rescan, status
0x2B SOURCE add or remove a stream source; the secret never travels
0x2C PROMPT, PROMPT-ANS reuse browser 0x0D and 0x0E

Spectrum budget: 16 bytes of bands plus a 16-byte header, 10 times a second, is about 320 bytes a second [estimate]. That fits even the lockstep rate. The spectrum is not sent while the window is hidden.

Position: the helper reports position every 100 ms while playing. The guest interpolates for the clock, so the link carries no 30 Hz timer.

Gapless: the helper schedules the next file when the current one has 5 s left.

5. Streaming sources#

Source Auth Work on the host Priority
Local folders none scan, play P0
Subsonic (Navidrome and others) user and password or token in the macOS Keychain getIndexes, getAlbumList2, stream, getCoverArt; guest sees track ids only P1
Internet radio none the helper plays the stream and reads ICY metadata P1
Podcasts (RSS) none fetch feed and enclosures on demand P2
Koel account on its server Koel has no Subsonic API [V: no "subsonic" in Koel's app/]; a separate adapter P2
Apple Music, Spotify paid account, DRM, closed APIs not supported out

Navidrome does not mark a song played on stream, only on scrobble with submission [R] (navidrome.org/docs/developers/subsonic-api). The adapter sends scrobble at the play threshold.

Account rule: adding a service is an explicit PROMPT (section 9) that names the host, the account and the data read. Tokens stay in the Keychain. The guest gets a track id and a proxy URL on 127.0.0.1.

6. Visualiser and reuse#

The helper runs the FFT on its output tap and sends 16 bands. The guest draws bars with theme colours and peak dots. A scope view would need raw samples, which the link cannot carry, so it stays in the helper's own window (P2).

Candidate Licence (checked) Use
mpv GPLv2+ default; LGPLv2.1+ with --enable-lgpl [R] (en.wikipedia.org/wiki/Mpv_(media_player)) optional helper, run as a separate process over IPC, not linked
cava MIT per package indexes [R] (chimera-linux, t2linux). Gentoo lists "MIT Unlicense" for later releases band layout reference; read its LICENSE before copying
projectM core LGPL-2.1-or-later [R] (MSYS2 package, 4.1.6) host-side option only
mutagen GPL-2.0-or-later [R] not used until a licence decision
MPD GPL [M]. Its idle command blocks until a subsystem changes and queues events [R] (git.pvv.ntnu.no mirror of doc/protocol.xml) model for STATE: push on change, not poll
Koel MIT [V: LICENSE.md]; getID3 and ffmpeg transcode [V: app/Helpers.php] reference for the library model; MIT notice kept if code is copied
Navidrome upstream licence not checked [M] test server only, never bundled
lofinity-player (local) no LICENSE file [V]; README dedicates it to a teacher's work ideas only; ask the owner before any code reuse

Kosmos OS music (src/apps/music/, server/services/musicLibraryService.ts) has no licence [V: primitives 5], so use it as a spec of fields only.

7. TempleOS audio: what is known#

  • TempleOS has a PC speaker path (its Snd and Play routines) [M]. Not run here.
  • This QEMU offers sb16, AC97, es1370, intel-hda, hda-*, virtio-sound [V: qemu-system-x86_64 -device help] and back-ends coreaudio, wav, dbus, none [V: -audio help].
  • pc-i440fx-9.2 lists no pcspk-audiodev property [V: -machine pc-i440fx-9.2,help]. A speaker route to the Mac therefore needs another mechanism. Unverified.
  • A web search for a TempleOS sound-card driver found nothing usable [R, weak sources]. No SB16, AC97 or HDA driver is known in TempleOS V5.03 [M]. Assume no guest audio until the M0 spike says otherwise.
  • The VM launch in scripts/boot-vm.sh has no -audiodev option [V].

8. Retro module (optional)#

A separate window: a HolyC note sequencer with a piano roll and tempo, playing on the PC speaker only if M0 finds a route. If there is no route, it runs silently and still shows the notes. It is off the critical path.

9. Security and consent#

  • Scoped access. Only folders the user picked are scanned. Symlinks are not followed out of a root. Roots are listed in Settings and removable.
  • No DRM circumvention. Protected files are counted as "protected, not played" and never decrypted.
  • Outward actions prompt. A new account, a new stream host, a podcast download or a write outside the app's data raises PROMPT (browser 0x0D) with the default "no".
  • Guest holds no secrets. Tokens, passwords and credentialed URLs stay on the host.
  • Path checks on the host. No .., must sit under a chosen root, length at most 1024.
  • Untrusted media is parsed on the host only, in the helper, with a timeout. A bad file is marked failed and does not stop a scan.

13. Test plan#

A folder of generated test tones: tests/music/fixtures/, made by scripts/gen-test-tones.sh (to write) with ffmpeg lavfi, so it is reproducible.

  • Tones at 440 Hz, 1 kHz and 20 kHz, 5 s, 44.1 and 48 kHz, mono and stereo.
  • Silence, a 10 ms click track (gap detection), a 60 s sweep (seek accuracy).
  • The same tone as MP3, M4A (AAC), ALAC, FLAC, WAV, AIFF, Ogg Vorbis.
  • Tagged copies with embedded art at two sizes.
  • Bad files: zero bytes, truncated FLAC, wrong extension, a tag claiming 1 GB (rejected, not read whole).
  • A duplicate pair at two paths with equal tags.

Checks: scan output against a golden JSON; seek and gap timings from the helper log; a grep of captured guest traffic for tokens and credentialed URLs; desk frame time in a scripted drive (aiwnios/drive.HC pattern [V]).

14. Risks#

  1. No guest audio (likely). The app is host-first; the retro module is optional.
  2. Codec gaps: AVFoundation lacks Ogg and Opus. Transcode on the host, measured on the fixtures.
  3. Link load from art and rows. Caching, paging, 64 px art, 10 fps spectrum.
  4. Licence creep (mutagen, mpv, projectM, unlicensed Kosmos OS code). No copying or linking without a written decision.
  5. Account services change APIs or terms. Subsonic only in P1.
  6. Large libraries on serial. Host SQLite, virtual lists, no full-library sends.
