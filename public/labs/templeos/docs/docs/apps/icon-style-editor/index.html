Icon Style Editor (app "Icons", desk3/03c-iconstyle.HC)

Edited 2026-10-27docs/apps/icon-style-editor.md

Open it with the dock icon (paintbrush) or the i key. Left: every app icon at Large (56), Dock (the Settings icon size, at most 56) and Small (24) on a light and a dark backdrop. Right: presets, ten pages of controls, Reset, Export, Import. Every change reaches the preview and the real dock at once (one style, one DrawIconTile).

Controls (page: what)#

  • Shape: corner radius (0 square to 100 circle), presets Square, Round, Squircle, Circle, squircle corners toggle (superellipse, exponent 4).
  • Fill: Solid, Linear (angle), Radial; 2 or 3 stops, each a swatch (lighter, tile colour, darker, 11 fixed colours); middle stop position.
  • Scheme: App accents, Mono, Duo, Pastel, Vivid, Sunset, Ocean, Gold, Desktop (follows the current desktop style), Custom; a 12 by 4 hue and lightness palette picks colour A and B; "one shared colour" uses A for every tile.
  • Tone: hue shift, saturation, brightness.
  • Depth: bevel strength and size, gloss band, inner shadow, "preview all pressed".
  • Shadow: drop shadow opacity, offset, blur; tilt (vertical squash) and reflection.
  • Glyph: stroke weight, filled shapes (0 is outline), size, offset x and y, colour (auto contrast, white, dark, tint).
  • Border: ring width, colour, opacity; glass tile (see-through, the dock pill and its blurred backdrop show through) and its opacity.
  • Extras: outer glow and radius, grain, fade when the app is closed, hover lift, glyph shadow, glyph glow.
  • Layout: dock tile size (Settings value), gap between tiles, name label on hover, "Time rebuild".
  • Presets: Default, Flat, Glass, Soft (neumorphic), Pop (gradient), 3D (skeuomorphic), Mono (line), Temple. Reset returns style and layout to the defaults.
  • Keyboard: Tab or Down next control, Up previous, Left and Right adjust (or choose), Space or Enter toggles and presses, Page Up and Down change page, m times a rebuild. Hover a preview tile for lift and its name; press on it for the pressed look.

Style string#

KSI1 followed by every parameter that differs from its default, as a two letter key and a number: KSI1 rd50 sq1 fl2 sc7 bv40 gl25 sd40 so3 sb6 gc2 rw1 rk1 ra50 ow30 or5 gn15. Export writes it into Notes (and opens Notes); Import finds the first KSI1 in Notes, resets the style and applies the line. A preset is the same kind of line. Keys are in is_k (03c), ranges in is_lo and is_hi.

Architecture#

  • is_v[] (the IconStyle) holds every parameter as an I64; the dock size, gap and label live in ks_dsize, ks_dgap, ks_ilabel. is_sig hashes the tile parameters; is_def says all are default.
  • DrawIconTile(x,y,size,app,state) (state: 1 pressed, 2 inactive, 4 hover). Default style: the old direct draw (RRFill and LIcon), so the dock costs what it did. Otherwise: colour tile per (app, size, signature, state) in a 256 slot two-way cache; shared planes per size (shape alpha, bevel bands, gloss, inner shadow, ring, grain, shadow and glow with a margin, radial index, row spans) built once per shape; glyph masks cached per (icon, size, weight, fill).
  • A tile is built from Fill32, a 64 entry ramp stepped in 16.16 fixed point (two pixels a store), and KsBlendA2D through the planes. A frame blits: shadow and glow planes, per row the soft edge pixels, then Copy32 (or LerpRow for glass) of the opaque run. Nothing is rebuilt while the signature is unchanged.
  • Sizes are quantised to multiples of 4 native pixels so a magnifying dock reuses tiles. The dock reaches DrawIconTile through the pointer ks_ictile (a call through a forward declaration does not reach a later definition on either HolyC).
  • Aiwnios: same file, no asm, integer paths; see aiwnios/drive-icons.HC for the headless driver.

Numbers#

QEMU x86 at 2880x1800 (ms a frame, average, before with 11 apps and after with 12 apps and the Icons app, default style): dock sweep warm 3.2 and 3.7, cold 4.0 and 5.0, drag large 6.5 and 6.6, drag small 4.7 and 4.7, full redraw 17.8 and 19.0. The default style takes the old direct path, so the rise is the twelfth icon and the wider dock. Rebuilding the 12 dock tiles (Glass preset, 104 px tiles): 2.5 ms with the planes and glyph masks cached, 4.8 ms with every plane and mask rebuilt (Layout page, "Time rebuild", or key m; also a serial line icons|rebuild|...). Aiwnios on Apple Silicon: 0.1 to 0.9 ms and 0.2 to 1.6 ms depending on the preset. Nothing is built while the style is unchanged; a frame only blits.

Limits#

Tilt is a vertical squash with a reflection, not a perspective. Glass uses the dock pill, so it shows blur only where the dock is translucent. Import reads Notes, not a file. Colours of Desktop scheme and tiles follow the desktop style; the default style in a dark desktop style keeps the old dark glyph. Weights above 100 percent use a blurred dilation. The Quit button is not an app tile and is unchanged.
