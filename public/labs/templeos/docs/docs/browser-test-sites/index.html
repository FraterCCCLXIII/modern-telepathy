Kosmos Browser: test sites

Edited 2026-10-27docs/browser-test-sites.md

Status: specification. Branch task/templeos-shell. Written 2026-10-27. Companion to browser-features.md (what must work) and browser-architecture.md (how it is built; the gates in its section j refer to these sites).

Rules for this list#

  • Public pages only, no logins, no accounts. Nothing here needs a password, and the harness never fills a form on a site outside this list.
  • One request per site per run, plus the subresources the page itself loads. Do not crawl links beyond the list. Wait at least 5 seconds between runs on the same site.
  • Forms are tested only where the page is a public demo or a local server. Add-to-cart on the OpenCart demo is allowed; checkout is not.
  • Pages change. The "what to check" column names things that are stable (a heading, a link, a structural feature) and not exact text. Each row says when it was last checked. As of this writing, none of these pages has been fetched by this pass; every row is a plan to verify at M1, not a result.
  • The harness records for each site: final URL, title, DLIST bytes per band, first-paint time, number of text runs, number of images, number of tiles, prompts raised, and a screenshot at scale 2.

Running the list#

  1. M1: navigate the 25 sites and the error fixtures with stream 1's engine. Record the table of numbers above per site. Do not paint yet.
  2. M2: paint tiers 1 and 2 (sites 1 to 5) and check the rows. Screenshots at scale 2 to apps/templeos-holyc/shots/browser-site-<n>.png (the existing shots/ folder holds the v0 screenshots).
  3. M3: run the shell actions (features section 1 to 3, 7, 9) on sites 1, 3, 6 and 11, and the error fixtures.
  4. M4: run tiers 3 to 7 and the local fixtures.
  5. M5: run the DevTools checks on sites 3, 6, 8, 16 and 17.
  6. M6: run all 25 sites three times; record the p95 latency per site.

Record results in tests/browser/results/ (stream 9); do not commit screenshots of pages that have a login or a personal account (none are on this list).

What is not tested here, and why#

  • Sites that need a login (email, banking, social feeds, shopping accounts): out of scope by the rules above.
  • Sites that require payment, checkout, or sign-up: out of scope.
  • Video DRM (Netflix, Spotify, YouTube Premium): out of scope (Widevine, features section 15).
  • Real-time sites that load thousands of requests (live sports, trading, streaming dashboards): out of scope in v1 for cost and latency reasons.
