apps-host: run Electron apps on the host, show them in the desktop

Edited 2026-10-27apps-host/README.md

Prototype. Python 3 standard library (Pillow for tests only). Design and numbers: ../docs/electron-apps.md.

Files: manifest.py schema, install.py fetch/verify/extract/policy/registry, perms.py approvals and workspace rules, launch.py spawn with a CDP pipe, attach.py targets/display list/screenshot/input, stream.py tile bridge, appd.py CLI and supervisor, tests/ (python3 -m unittest discover -s tests; fidelity.py and stage3_fake_guest.py need a running app). The guest end is ../desk3/03d-electronapp.HC (off until KS_ELECTRON is defined, not yet run in a VM).
