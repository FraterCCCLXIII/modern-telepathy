FAQ

Questions about the desktop.

Short answers, with links to the long ones.

Is it safe to run?

Run it in a VM, which is where it belongs. TempleOS has no memory protection, so a bad HolyC app can take the guest down. What we add is protection around it: signed packages, permissions you approve, and keys that stay on your Mac. Security lists what is and is not promised.

Why HolyC?

It is the language of the system underneath. One compiler is the shell, the scripting language and the app language, and it compiles as you type, so a change is live in seconds. HC+ is our plan to fix its rough edges without losing that.

Does it replace macOS or Windows?

No. It runs in a window on top of your system, as an emulated machine or as a native window.

Which Macs does it run on?

Native needs an Apple Silicon Mac, and that is the one combination we have tested. Classic should run anywhere QEMU does. See Requirements and Download.

Can I use it on Windows or Linux?

Classic should, through QEMU. We have not tried it, and the Download page says so.

Is it free? What is the licence?

TempleOS is in the public domain. The licence for our desktop is not yet decided; this site marks it as a placeholder. Third-party parts are listed on Notices.

Is there AI in it?

Not yet. It is the direction: agents under rules you set, with your keys on your Mac. AI in the OS shows the plan and the status of each part.

What is Creation Studio?

The creative suite we are building: sheets, photos, vectors, documents and slides. Sheet is native, Photo and Vector run today as streamed windows, the rest are planned. See the suite.

Can I install other apps?

The package format and installer are designed and prototyped on the host. The desktop side is written but not yet run in a VM, so apps are loaded from source today.

Who made TempleOS?

Terry A. Davis. The founder and the creation of TempleOS.

How do I report a bug or a security problem?

Open an issue in the repository. A dedicated security contact is not set up yet; the Security page marks it as a placeholder.

Still curious?

Try the desktop in your browser, or read the docs.
