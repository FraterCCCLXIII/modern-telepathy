Get started

Boot it in a few minutes.

You need QEMU, a TempleOS ISO and a Mac or Linux box.

Run it

git clone https://github.com/FraterCCCLXIII/templeos
cd templeos
scripts/run.sh /path/to/TempleOS.ISO

The first run builds a saved VM image, about 2.5 minutes. After that the desktop is up in about four seconds.

Keys

T
On the splash: show the original TempleOS screen.
F12
Toggle between Kosmos and the original TempleOS view.
R
On the splash: restart.
b
Run the benchmark suite.

This website

cd projects/templeos-site
npm run dev    # http://localhost:4321
npm test

Read the docs.

Every app has a design note with its numbers and limits.
