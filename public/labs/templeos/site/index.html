Kosmos Temple Desktop

A modern desktop, written in HolyC, on TempleOS.

Windows, a dock, a browser and sixteen apps, all in HolyC, on the 640x480 operating system Terry A. Davis wrote.

Boots to the desktop in about four seconds from a saved VM image.

01 · Desktop

One screen, five styles.

Switch between macOS, Windows 11, glass and more, light or dark. Every window, icon and font is a setting, and the defaults are pixel-identical to the first build.

The desktop →

02 · Apps

Native apps, not demos.

Files, Notes, Calendar, Clock, a spreadsheet, a music player and a chat with animated avatars. Each one is one HolyC file.

All apps →

03 · Browser

The web, painted by HolyC.

A browser whose pages are drawn by the desktop itself, with a host engine behind it for modern sites.

The browser →

04 · Type

Real fonts on a 16-colour OS.

A v2 text engine draws anti-aliased Inter, Computer Modern and Liberation at any size, with a native Font Book.
