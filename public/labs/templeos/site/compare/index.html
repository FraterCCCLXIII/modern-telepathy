Original, Classic or Native.

Three ways to run it, with the differences that matter. Where one cannot do something, the table says so.

Numbers are from the repository notes, measured on an Apple Silicon Mac at 2880x1800. Classic there runs x86 under emulation.

Which one?

Choose Native

if you are on an Apple Silicon Mac and want it fast, in a plain window.

Choose Classic

if you want the full original system underneath, or you are not on Apple Silicon.

Keep Original

if you want TempleOS exactly as it was. It stays one key away in both.
