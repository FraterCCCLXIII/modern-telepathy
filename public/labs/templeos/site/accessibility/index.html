Accessibility

Where we are.

We have not audited the desktop for accessibility. This page lists what exists, and what does not, so nobody has to guess.

Status: not audited.

What exists.

Size

Display scale at 1x or 2x, and six font families, set in Settings.

Contrast and modes

Five styles, each with light and dark.

Motion

Animations can be turned off in Settings, and the desktop then cuts instead of fading.

Keyboard

Number keys open apps in dock order, Tab brings the next window forward, and Notes and Calculator take typing. Coverage is not complete.

Known gaps.

GapStatus
Screen reader supportNot available
Full keyboard operation of every controlNot complete
Contrast checks against WCAGNot done
Text size larger than the largest font settingNot available
Captions or transcripts for demo mediaNo media yet

This website is plain HTML with visible focus, a skip link, labelled controls and a light and dark mode. We have not run an audit on it either.
