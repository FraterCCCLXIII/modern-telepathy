Sixteen apps. One file each.

Sorted by what you want to do. They share one toolkit, one theme system and one text engine.

Notes

Sheet

A spreadsheet with formulas.

Calendar

Months, events and a local store.

Calculator

A plain calculator in the desktop style.

Files

Browses the real TempleOS drives and the Demo, Apps and Doc folders. Opens text, runs programs.

Explore

See the web, the weather and a bit of play.

A player for the host music library.
